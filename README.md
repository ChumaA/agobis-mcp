# Agobis for Cursor

Connects Cursor to [Agobis](https://www.agobis.com) fleet management over MCP
(`https://mcp.agobis.com`). Ask about vehicles, live locations, drivers, rides,
trips and maintenance due.

- **Read-only.** The connector requests only the `agobis.read` scope.
- **Sign-in:** OAuth with your Agobis account; no API key to paste.
- **Requirements:** an Agobis organization on the Starter plan or above, with
  **Allow AI connectors** turned on under Organization settings.

Support: support@agobis.com
